# **App Name**: BizTrend AI

## Core Features:

- User Authentication: User authentication (Sign-up/Login) using Firebase Auth.
- Data Upload and Parsing: Upload CSV files with automatic column detection for data analysis.
- AI Insights Generation: Use an AI tool via OpenAI API to generate insights from uploaded data.
- Data Visualization: Visualize data through automatically-generated charts.
- Subscription Management: Subscription tiers using Razorpay UPI: Free, Pro, Enterprise.
- Dashboard UI: Dashboard presenting key metrics.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to represent clarity and insight. This hue subtly references data visualization, without being cliché.
- Background color: A light, desaturated blue (#E5F6FD) to ensure readability and a calm user experience.
- Accent color: A contrasting orange (#FF9933) to highlight key actions and important data points. This provides visual interest against the analogous blue tones.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral look that ensures readability and professionalism.
- Use clean, geometric icons from Heroicons to maintain a consistent and modern aesthetic.
- Mobile-first responsive design using a grid layout to ensure optimal viewing across devices.
- Subtle transitions and animations to enhance user experience without being distracting.
